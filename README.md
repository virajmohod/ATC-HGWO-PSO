# ATC-HGWO-PSO

Adaptive Tent Chaotic Hybrid Grey Wolf–Particle Swarm Optimization for Wrapper-Based Feature Selection in IoT Intrusion Detection Systems.

---

## Features

- Tent Chaotic Initialization
- Adaptive GWO
- Adaptive PSO
- Binary Wrapper Feature Selection
- KNN Fitness Evaluation
- Multiple Benchmark Datasets
- Automatic Publication Graphs
- Statistical Analysis
- LaTeX Table Export
